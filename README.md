# Trabalho-Econometria-I---AF.MR
Trabalho Atividade Empírica de Econometria I, realizada por Artur Ferezin e Marco Ravaglia da FGV EESP, sobre corresidência com idosos e as decisões de estudo e trabalho dos jovens brasileiros.
## Como rodar
1. Baixe o repositório (Code > Download ZIP) e descompacte.
2. Abra o script no RStudio e use Session > Set Working Directory > To Source File Location.
3. Rode o script inteiro. Tabelas e figuras são salvas em `resultados/`.

Para montar a base do zero, retire o `.rds` da pasta e coloque nela o
PNADC_2025_visita1_20260923.zip, disponível em:
https://ftp.ibge.gov.br/Trabalho_e_Rendimento/Pesquisa_Nacional_por_Amostra_de_Domicilios_continua/Anual/Microdados/Visita/Visita_1/Dados/
